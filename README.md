# Plinco Inc.

An incremental / idle game where you build a Plinko empire one bouncing chip at a time.

## Status

Pre-alpha — currently bootstrapping the repository. The playable build will live in [`/docs`](./docs) and be served via GitHub Pages.

## Play

Once published, the game will be available at:

**https://nors3ai.github.io/Plinco-Inc-idle/Plinco-Inc-Game**

(GitHub Pages will serve out of the `/docs` directory on the default branch.)

## Concept

- Drop chips down the Plinko board to earn currency.
- Reinvest earnings into more pegs, more chips, multipliers, and automation.
- Idle progression — keep earning while you're away.
- Prestige loops, upgrades, and unlockables stack on top.
